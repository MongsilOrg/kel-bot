# kel-bot

이터널 리턴 KEL 스크림의 팀 신청과 추첨을 관리하는 Discord 봇. 슬래시 명령 없이 채널에 상주하는 대시보드 하나로 지역 단위 신청을 받고 매일 자동 추첨한다.

## 주요 기능

- 지역 단위 팀 신청 — 서버 닉네임 `지역) 이름`에서 지역 자동 파싱
- 매일 00:30(KST) 자동 추첨, 정원 도달 시 즉시 추첨
- 탈락 팀에 다음날 우선권 자동 발급·적용(17시 데드라인까지 미사용 시 소멸)
- 참가 14팀 이상이면 8팀 선정 대신 전원을 두 중대로 분할 편성
- 채널 상주 영구 대시보드(신청/취소/우선권 버튼, 실시간 현황)

## 동작 방식

21시 일일 리셋 → 00:30 추첨 → 17시 데드라인 스케줄로 돈다. 상태는 DB 없이 `data/*.json`에 원자적으로 저장하며, 재시작 시 다운타임 동안 놓친 리셋·추첨·데드라인을 멱등적으로 보정한다. UI는 discord.py LayoutView.

## 기술 스택

Python, discord.py, discord.ext.tasks 스케줄러, 파일 기반 JSON 영속화. NAS 상시 구동.
