# kel-bot

이터널 리턴 KEL 스크림의 팀 신청과 추첨을 관리하는 Discord 봇. 슬래시 명령 없이 채널에 상주하는 대시보드 하나로 신청을 받고 매일 자동 추첨한다.

## 기능

- 지역 단위 팀 신청. 서버 닉네임 `지역) 닉네임`에서 지역을 자동 파싱한다
- 매일 0시 30분 1차 추첨. 정원 미달이면 보류했다가 정원 도달 시 즉시 추첨한다
- 17시까지 추첨이 성사되지 않으면 그날 스크림을 취소하고 다음날로 즉시 전환한다
- 탈락 팀에 다음날 우선권을 자동 발급한다. 우선권 팀은 다음 추첨에서 우선 선정되고, 우선권은 해당 일자에만 유효하다
- 14팀 이상 모이면 8팀 선정 대신 전원을 두 중대로 나눠 편성한다
- 대시보드 버튼으로 신청, 취소, 우선권 수동 관리

## 동작 방식

하루 주기는 21시 리셋, 0시 30분 추첨, 17시 데드라인 순서로 돈다. 상태는 DB 없이 `data/` 아래 JSON 파일에 원자적으로 저장한다. 재시작하면 다운타임 동안 놓친 리셋, 추첨, 데드라인을 부팅 시점에 멱등하게 보정한다.

## 실행

```bash
pip install -r requirements.txt
cp .env.example .env   # 값 채우기
python main.py
```

## 설정

| 키 | 설명 |
|---|---|
| DISCORD_TOKEN | 봇 토큰. 필수 |
| APPLY_CHANNEL_ID | 대시보드를 띄울 채널 ID. 필수 |
| GUILD_ID | 서버 ID. 선택 |
| LOG_CHANNEL_ID | 로그 채널 ID. 선택 |
| RESET_HOUR | 일일 리셋 기준 시각. 기본 21 |
| DRAW_HOUR | 1차 추첨 시. 기본 0 |
| DRAW_MINUTE | 1차 추첨 분. 기본 30 |
| DEADLINE_HOUR | 신청 마감 데드라인 시각. 기본 17 |
| TEAM_SLOTS | 추첨 선정 팀 수. 기본 8 |
| SENTRY_DSN | Sentry DSN. 선택. 비어 있으면 이벤트를 전송하지 않는다 |
